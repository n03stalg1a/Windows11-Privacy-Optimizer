# Windows 11 Privacy Optimizer

This batch script is designed to enhance the privacy settings of Windows 11 by disabling various telemetry features, background applications, and unnecessary services that may compromise user privacy. 

## Features

- **System Restore Point**: Automatically creates a restore point before making any changes, allowing users to revert to a previous state if needed.
- **Comprehensive Privacy Settings**: Disables telemetry, advertising IDs, location services, Cortana, background apps, and more.
- **Progress Indicators**: Provides real-time feedback on the optimization process with a progress bar and percentage completion.
- **User-Friendly Interface**: Includes a loading screen and color-coded output for better visibility and aesthetics.

## Usage

1. Download the script and save it as `Windows11-Privacy-Optimizer.bat`.
2. Right-click the file and select "Run as administrator" to execute the script with the necessary permissions.
3. Follow the on-screen instructions and wait for the optimization process to complete.
4. Restart your computer for all changes to take effect.

## Disclaimer

This script modifies system settings that may affect how you use your computer. Please review the changes before running the script and ensure you understand the implications. Always back up your registry and important data before making system modifications.
